# Start Deutsch 1 Prep

A 25-day study app for the **Goethe-Zertifikat A1: Start Deutsch 1** exam (Tuesday, 24 November 2026).

- Daily plan that counts down to the exam, with catch-up for missed days
- Drills in the exact exam format: Hören (3 parts), Lesen (3 parts), Schreiben (form + short message), Sprechen (introduction, topic cards, request cards)
- Flashcards for about 440 words from the Goethe A1 word list, with spaced repetition
- Three timed mock exams, plus links to the official Goethe practice papers
- Works offline and can be added to your phone's home screen

Progress is saved in your browser. Use **Settings → Backup** to move it between devices.
Listening tasks use your device's German text-to-speech voice.

Live site: https://gedewon.github.io/start-deutsch-1/
